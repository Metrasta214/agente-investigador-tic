# Fuentes de Radar TIC

Las fuentes se sirven desde este directorio. No se requieren Google Fonts,
un CDN ni una instalación de fuentes en Windows.

- **Glacial Indifference**, Alfredo Marco Pradil: regular y bold WOFF2, obtenidos
  de https://github.com/ms-studio/webfont-glacial-indifference.
  El OTF original se conserva como referencia. La licencia OFL completa y el
  copyright se extrajeron de sus metadatos a `Glacial-Indifference-License.txt`.
- **DM Sans**, familia variable: archivo oficial de
  https://github.com/google/fonts/tree/main/ofl/dmsans.
  Su licencia se conserva en `DM-Sans-OFL.txt`.

Los títulos utilizan Glacial Indifference; el texto y los controles utilizan
DM Sans. Ambas familias usan `font-display: swap`.
